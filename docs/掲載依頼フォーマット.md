# 掲載依頼フォーマット（メールでご記入いただく用）

「応援傍聴ナビ」への掲載をご希望の方に、このままお送りください。
＊は必須、それ以外は分かる範囲・任意でかまいません。

---

## 1. 事件について

- 事件名＊（例）情報公開請求をめぐる訴訟
- 当事者（例）原告 従業員 ／ 被告 〇〇株式会社
- 裁判官（分かれば）
- 争点（1行に1つ、箇条書きで）
  - （例）〇〇の事実があったか
  - （例）会社に安全配慮義務の違反があったか
- タグ（分かれば・1行に1つ）（例）労働、パワハラ
- 終結日（終結した事件のみ・任意）
- 終結の種類（終結した事件のみ・任意）（例）判決、和解、取下げ

## 2. よびかけ（任意）

どんな裁判か、傍聴や支援をお願いする文章など（段落を分けたいときは空行を入れてください）

- よびかけ文
- 呼びかけ団体・お名前（例）A社従業員
- 連絡先（公開してよいもの。メールアドレスなど）

## 3. 報道・掲載（あれば・任意）

新聞・雑誌等で取り上げられたものがあれば、1行に1つ
（例）〇〇新聞で報道されました https://...

## 4. 直近の期日（分かれば）

- 期日＊（日付）
- 時刻
- 種別（例）第3回口頭弁論、和解、判決言渡
- 裁判所（例）東京地方裁判所
- 法廷（例）610号法廷
- 傍聴できますか（できる／非公開・要確認）
- この回の原告の主張（1行に1つ・任意）
- この回の被告の主張（1行に1つ・任意）

## 5. 資料（あれば）

資料ごとに以下をお願いします（複数あれば繰り返し）

- 資料名＊（例）訴状、第1準備書面、甲3 〇〇
- 提出者側（原告側／被告側／裁判所／その他）
- 種別（主張書面／証拠／判決・決定／その他）
- 提出日
- ファイル（PDF・PNG・JPEG、20MBまで。添付してお送りください）
- この書面で主張していること（1行に1つ・任意）

## 6. 写真（あれば）

- ファイルを添付してください（JPEG・PNG・WebP、12MBまで）
- 説明（1行・任意）（例）提訴後の記者会見にて

**写真は、人の顔・氏名・住所が写り込んでいないかご確認のうえお送りください。**
